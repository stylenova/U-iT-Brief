# U-iT-Brief — Опросник для сайта

## Быстрый старт

1. Установи зависимости:
   ```
npm install
   ```
2. Запусти локально:
   ```
npm run serve
   ```

---

## Как деплоить на GitHub Pages (gh-pages)

1. Собери проект:
   ```
npm run build
   ```
2. Выложи на GitHub Pages:
   ```
npm run deploy
   ```
3. Сайт будет доступен по адресу:
   ```
https://stylenova.github.io/U-iT-Brief
   ```

---

## Как это работает

- Весь исходный код и настройки — в репозитории.
- Папка `dist/` генерируется автоматически (её нет в git, см. `.gitignore`).
- Команда `npm run deploy` берёт содержимое `dist/` и выкладывает в ветку `gh-pages`.
- GitHub Pages показывает сайт из ветки `gh-pages`.

---

## Как подключить второй remote (например, GitHub) в Sourcetree

1. Создай репозиторий на GitHub.
2. В Sourcetree открой свой проект.
3. В меню "Репозиторий" → "Настройки репозитория" → "Remotes" → "Добавить":
   - Remote name: github
   - URL: https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
   - Сохрани.
4. Теперь можно пушить в Bitbucket и GitHub.

---

## .gitignore

- В git не попадают служебные папки (`node_modules`, `dist`, `.env`, временные файлы).
- В репозитории только исходники и нужные для работы файлы.

---

## Если что-то не работает

- Проверь, что все зависимости установлены (`npm install`).
- Проверь, что в package.json есть секции `homepage` и `deploy`.
- Если нужна помощь — смотри этот README или обратись к разработчику.
